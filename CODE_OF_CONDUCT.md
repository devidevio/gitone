# Code of conduct

This project follows the
[Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).
That document is the policy; it is linked rather than copied so it cannot drift
from the version it claims to be.

What it comes down to here: criticism of the code is welcome and wanted -
especially about the ownership boundary, where being wrong is expensive.
Criticism of a person is not. Disagree with the design, the output format or
the decision to refuse rather than guess as sharply as you like, and leave the
contributor out of it.

## Reporting

Write to the maintainer at the contact address in the
[imprint](https://gitone.io/imprint).

For behaviour inside GitHub's own spaces - an issue, a pull request, a
discussion - [GitHub's abuse report](https://github.com/contact/report-abuse)
is the second route, and it does not go through the maintainer at all.

Reports go to the maintainer and nobody else. You will get an answer, and the
fact that you reported stays between us unless you say otherwise.

GitOne is maintained by one person, which means there is no committee to appeal
to - so the bar for acting is what a reasonable contributor would consider
fair, not what the maintainer finds convenient. Consequences range from a
request to edit a comment to a permanent ban from the repository.

A security problem is not a conduct problem: see [SECURITY.md](SECURITY.md).
